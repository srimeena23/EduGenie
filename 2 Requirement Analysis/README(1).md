# EduGenie

EduGenie is an AI-powered learning assistant built with FastAPI and Google Gemini.

## Features

- Ask educational questions
- Get simple explanations
- Summarize study material
- Generate quizzes
- Create personalized learning paths

## Technologies

- Python
- FastAPI
- Google Gemini API
- Jinja2
- HTML
- CSS
- JavaScript
